Tools for asset processing.

- convert_map.py: Convert source map image to tileset/tilemap binaries.
- build_wood_collision.py: Build wood map collision.bin from red mask images (with overlay previews).
- verify_tiles.py: Verify generated tileset/tilemap against source image.
- build_esp32s3.sh: One-shot ESP32-S3 firmware build helper (loads /opt/esp/idf).
